# Internationalization (i18n)

Nexio is language-agnostic: memory, intent routing, search, and the UI work
in any language. English is the source of truth and the fallback; model-facing
prompts stay in English for reliability, with
"Reply in the language of the user's latest message unless the user asks
otherwise." Tool names and JSON schemas stay English.

## Strings

- All user-facing strings live in `src/main/i18n/locales/<tag>.json`
  (`en.json` is canonical). Main and renderer share one core
  (`src/shared/i18n.ts`, mirrored in `src/renderer/app.js` — keep in sync):
  key lookup, `{placeholders}`, and `Intl.PluralRules`-driven plurals
  (Russian/Arabic forms work). No string concatenation, no `(s)` plurals.
- Shipped locales: English (complete) + Vietnamese (complete, proves the
  pipeline). `npm run i18n:check` fails CI on missing keys, unused keys,
  and placeholder mismatches; untranslated keys warn.
- Pseudo-locale (`NEXIO_PSEUDO_LOCALE=1`): expands text 30–40% with accents
  to catch overflow/truncation in layouts.
- Language setting: Settings > General > Language, "System default"
  (default, from `app.getLocale()`, falls back to English). Applies
  immediately, no restart (tray + menu rebuild).

## Adding a language

1. Copy `en.json` to `<tag>.json`, translate every value (keep
   `{placeholders}` identical).
2. Optional: add `src/main/i18n/intents/<tag>.json` (trigger phrases for
   the fast path) plus one test in `tests/unit/memory.test.ts`.
   A missing pack never breaks anything — the model call runs instead.
3. Run `npm run i18n:check`, `npm run typecheck`, `npx vitest run`.

## Language-agnostic memory

- No per-language regex in the decision path. A data-driven fast path
  (`intents/<locale>.json`, may only SKIP the model call on confident
  match) plus one cheap classifier call returning
  `{intent, text, language}` over the current + last 2 user messages only.
- `text` stays in the user's own words (never translated); the BCP-47 tag
  is stored on the memory. Offline (no provider) falls back to
  `/remember` / `/forget` + the Memory view — never word-guessing.
- Safety is provider-independent: schema validation, secrets/PII scan,
  300-grapheme cap, provenance (user messages only; tool/file/web output
  forces the confirmation card).

## RTL, fonts, formats

- `dir="auto"` on the composer and message blocks; `<html dir>` mirrors the
  layout for RTL UI locales; code blocks/paths/key caps stay LTR
  (`dir="ltr"`, isolate). Text-related CSS uses logical properties
  (`margin-inline`, `inset-inline`, `text-align: start`).
- Font stack: bundled Geist/JetBrains Mono for Latin + system fallbacks per
  script (PingFang, Hiragino, YaHei, Yu Gothic, Malgun Gothic, Noto Thai /
  Arabic / Devanagari). No embedded CJK fonts. Line-height 1.6 for
  CJK/Thai/Devanagari.
- Dates, times, numbers, sizes, durations, relative times use `Intl` with
  the UI locale. Limits count grapheme clusters (`Intl.Segmenter`), never
  UTF-16 slices. NFC for comparison/storage keys; original bytes on disk.
- Search: FTS5 `unicode61 remove_diacritics` + trigram index so CJK/Thai
  match; `Intl.Segmenter` tokenization with locale-aware case folding.
- IME: composition (`isComposing` / keyCode 229) never submits or triggers
  shortcuts. Hotkeys render through the platform key-label helper.

## Supported languages (honest status)

| Area | en | vi | es fr de pt it | zh ja ko | ru ar hi id tr |
|---|---|---|---|---|---|
| UI strings | complete | complete | fallback en | fallback en | fallback en |
| Intent fast-path packs | yes | yes | yes | yes | yes (ar hi ru tr id) |
| Classifier/router | any language via model | same | same | same | same |
| Search/recall | yes | yes | yes | trigram + segmenter | yes |

Remaining English-only spots (tracked, not silent): folder-rule
prohibition parsing (`NEVER_RE`), stopword list coverage beyond
en + CJK/Thai particles, the `forget everything` typed confirmation,
workflow transform `uppercase`/`lowercase` (locale-blind by design).
